3. Important backend integration

   This component expects the following endpoints, which you still need to implement unless they already exist.
   Endpoint => Purpose
   - POST /api/auth/login => Validate credentials, verify the password hash, and establish a secure session
   - /api/auth/google => Start Google OAuth authentication
   - /dashboard => Student learning dashboard
   - /register => New student registration
   - /forgot-password => Password recovery

Security notes:

- Store password hashes, never plaintext passwords.
- Use secure, HTTP-only session cookies.
- Protect /dashboard on the server so unauthenticated users cannot access it.
- Validate credentials and rate-limit login attempts on the backend.
- The component's Google URL is a placeholder route; configure it to match your chosen authentication library.
